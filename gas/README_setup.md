# Google Apps Script 버전 설정 가이드

## 개요
`자산계획_v3.xlsx` → **Google Sheets** 로 이전한 뒤,  
`Code.gs` + `dashboard.html` 을 Apps Script에 붙여넣으면  
URL 하나로 외부에서 실시간 대시보드를 볼 수 있습니다.

---

## Step 1. Excel → Google Sheets 가져오기

1. [drive.google.com](https://drive.google.com) 에서 **새로 만들기 → 파일 업로드**
2. `자산계획_v3.xlsx` 업로드
3. 업로드된 파일을 더블클릭해서 열기
4. 상단 메뉴 **파일 → Google 스프레드시트로 저장**

> ⚠️ 시트 이름이 **자산현황, 부동산계획, 결혼계획, 월별저축** 네 가지가 있어야 합니다.

---

## Step 2. Apps Script 프로젝트 생성

1. Google Sheets에서 **확장 프로그램 → Apps Script** 클릭
2. 왼쪽 파일 목록에서 `코드.gs` (기본 파일) 클릭
3. 내용 전체 삭제 후 `Code.gs` 내용 붙여넣기
4. 왼쪽 **+** 버튼 → **HTML 파일** → 이름을 `dashboard` 로 입력  
   (Apps Script가 자동으로 `.html` 추가)
5. 생성된 `dashboard.html` 내용 전체 삭제 후 `dashboard.html` 내용 붙여넣기
6. **저장** (Ctrl+S)

---

## Step 3. 웹 앱 배포

1. 우측 상단 **배포 → 새 배포** 클릭
2. 유형: **웹 앱**
3. 설정:
   - **설명**: 민엽현지 자산관리 대시보드
   - **다음 사용자로 실행**: 나 (내 Google 계정)
   - **액세스 권한**: `링크가 있는 모든 사용자` (외부 공유 원할 시)  
     또는 `Google 계정이 있는 모든 사용자`
4. **배포** 클릭 → 권한 허용
5. 생성된 **웹 앱 URL** 복사

---

## Step 4. 접속 확인

복사한 URL을 브라우저에서 열면 대시보드가 표시됩니다.  
Google Sheets 데이터를 수정하면 새로고침 시 즉시 반영됩니다.

---

## 데이터 업데이트 방법

| 항목 | 방법 |
|------|------|
| 자산 현황 | Google Sheets **자산현황** 시트에서 직접 수정 |
| 저축 추이 | **월별저축** 시트 수정 |
| 부동산/결혼 | **부동산계획 / 결혼계획** 시트 수정 |
| 대시보드 반영 | 웹 앱 URL 새로고침만 하면 됨 (Python 재실행 불필요) |

---

## 현재 방식 vs GAS 방식 비교

| | 현재 방식 (Python) | GAS 방식 |
|--|--|--|
| 데이터 저장 | 로컬 Excel | Google Sheets (클라우드) |
| 대시보드 생성 | `python build_dashboard_html.py` | 자동 (URL 접속 시 서버에서 렌더링) |
| 외부 공유 | GitHub Pages URL | 스크립트 URL (더 간단) |
| 데이터 갱신 | Python 재실행 필요 | Sheets 수정 → 새로고침 |
| 두 사람 동시 입력 | 불가 (파일 충돌) | 가능 (Sheets 동시 편집) |
| 오프라인 사용 | 가능 | 불가 |

---

## 주의사항

- GAS 웹 앱 실행 속도: 첫 접속 시 **2~5초** 소요 (서버에서 Sheets 읽는 시간)
- 배포 후 코드 수정 시 **배포 → 새 배포 (또는 기존 배포 업데이트)** 필요
- `액세스 권한: 모든 사용자` 설정 시 URL을 아는 누구나 접속 가능
