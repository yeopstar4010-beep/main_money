## 시트 구성 (5개)

| 시트 | 역할 | 업데이트 시점 |
|------|------|--------------|
| **대시보드** | 순자산 현황 + 2027년 자금 계획 요약 | 자동 (타 시트 입력 시) |

## 입력 순서

### 지금 당장
1. `자산현황` 시트 — 현재 잔액 업데이트
2. `월별저축` 시트 — 기준 순자산 확인 (현재 4억 5천만)

### 대출 실행 시 (2027년 하반기)
3. `부동산계획` 시트 — 대출 금액·금리·월 상환액 입력
4. `월별저축` 시트 — 이벤트 금액 수정 (대출 확정 후)

### 결혼 준비 시
5. `결혼계획` 시트 — 업체 계약 시 실제 금액 입력
6. `결혼계획` 시트 — 하객 수 확정 후 축의금 시뮬레이터 업데이트

### 매월
7. `자산현황` 시트 — 잔액 업데이트
8. `월별저축` 시트 — 수입·지출 입력
